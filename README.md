# 璀璨圣诞树 · Merry Christmas

本目录是基于 [nobody-r/christmas-tree](https://github.com/nobody-r/christmas-tree) 的静态构建，
仅把内置的 8 张占位图换成 `photos/square/` 下的个人照片（512×512 居中裁切），并把照片环绕半径
按照片数量自适应，避免 57 张挤在一起。

- 在线：GitHub Pages → main → / (root)
- 原项目未附带 LICENSE 文件；若要长期公开保留，请考虑注明原作者或征得作者同意。
- 照片原图在 `photos/`，树/相册使用 `photos/square/`。
