# 璀璨圣诞树 · Merry Christmas

本目录是基于 [nobody-r/christmas-tree](https://github.com/nobody-r/christmas-tree) 的静态构建，
仅把内置的 8 张占位图换成 `photos/square/` 下的个人照片（512×512 居中裁切），并把照片改成沿树身螺旋悬挂（4.5 圈，按锥面面积分布），照片缩到 0.68 倍，鼠标悬停/捏合时放大；点击照片（或相册缩略图）可以放大查看原图；滚轮缩放或双指捏合时，照片和树体粒子/礼盒/彩球一起爆开，在空中漂浮并绕树身旋转约 5 秒（照片面向镜头缓慢漂移、整体曝光提高），然后一起回到树身螺旋；漂浮期间转动视角，屏幕上最居中的那张照片会自动放大。点击空白处不再触发散开。
